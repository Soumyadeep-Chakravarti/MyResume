# MyResume

**Description:** Full-Spectrum Software Architect portfolio with dual-mode interactive experience.

**Repository:** [github.com/Soumyadeep-Chakravarti/MyResume](https://github.com/Soumyadeep-Chakravarti/MyResume)

**Status:** Under construction.

## Architecture

Two distinct viewing modes:

1. **Simplified Version** — mobile phone mockup, minimal animations, recruiter-friendly
2. **Cinematic Version** — full immersive experience with dynamic animations, camera movements

### Transition Sequence

1. Toggle activated → phone mockup closes
2. Camera swivels to laptop on scene
3. Laptop opens → screen expands to fill viewport
4. Cinematic resume launches with animated section transitions

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- GitHub API integration
- Client-side caching
- Responsive design (mobile + desktop)
